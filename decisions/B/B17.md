## Decision

Whenever an agent tells a person that an artifact or feature now exists, the
same message names the decision node that governs it, as ID plus title. A
node created during the work is announced at the point the work is reported,
not deferred to a closing list.

## Why

On 2026-09-02 the agent reported "the placement inbox is built" without
saying that B14 had been created to govern it. The owner had to ask which
decision governed the inbox, and observed that the build was announced but
its decision was not. A3 makes AI decisions visible in the tree; A5 makes
them legible in chat. Neither is served if the person hears about the
artifact and not the decision behind it, because the decision is exactly
the part they may want to overrule. Announcing at the moment of reporting,
rather than in a summary, keeps the two attached in the reader's mind.

## Consequences

- CLAUDE.md protocol: every "I built X" is accompanied by "governed by
  ID title".
- The tool lists uncommitted node changes so the agent has the exact
  ID-plus-title lines to report (C7).
