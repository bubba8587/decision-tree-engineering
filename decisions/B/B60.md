## Decision

An unratified leaf is not a block, but before a tree agent first builds new work under it (a child leaf, a spec, an artifact) the agent runs one contest: it constructs the alternatives (keep, opposite, deletion, optionally a variant), builds each far enough to scope its cost, judges them against the leaf's parents alone, records the verdict on the leaf, and moves on. Parents are read as the rubric and never reopened; siblings are not touched; children and citing artifacts count for nothing, not even as cost. A contested leaf is settled: it is acted on without re-asking until a human ratifies it or an agent supersedes it. Re-homing text that already governs built code is not new work and owes no contest: an import, a fold, a move of mechanics into a spec. A rewrite the owner directs settles the leaf as a contest would. A builder that works from a spec never contests, because it never sees the tree.

## Why

B7 surfaces unratified leaves instead of blocking on them, and asks agents not to treat them as truth. A model cannot ignore what is in its context, so the only way to stop an unratified leaf from acting as truth is to put its competitors beside it. Building and costing the alternatives does that, and it leaves the owner a comparison to ratify against rather than a bare proposal. A7 forbids re-questioning, so the contest runs exactly once per leaf and its result is recorded; a second pass needs an explicit flag. Children are excluded because a better leaf may be simpler and need none of them; counting them would be sunk cost defending the incumbent. Text that already governs built code is a record of what was decided, not a new decision, and an owner who rewrote a leaf has already weighed it. Known limitation, accepted: the judge is the model that wrote the leaf; the rubric being written down first makes the bias inspectable, not absent.

## Consequences

- `dte contest <ID>` prints the rubric and the slots; `--record` writes the verdict and, for a non-keep winner, the successor.
- An owner-directed rewrite is logged in History as the owner's; no Contest section is owed.
