## Decision

A spec may say `covers: <globs>` in a comment line near its top. Every file the globs match is built to that spec: it counts as cited through the spec, `show` lists it "via" the spec, and `blast` runs leaf, spec, then those files.

## Why

A rule about a whole class of files (every component, every store) would otherwise need the same citation pasted into every member, which is noise that rots. The spec is where the class's rule already lives, so the spec is where its reach is declared.

## Consequences

- Only a comment line counts, so a markdown heading that says "covers:" is not a scope.
- A covers glob that matches nothing is stale and fails `coverage --check`.
- A file still cites what is specific to it; a file with nothing specific needs no header.
