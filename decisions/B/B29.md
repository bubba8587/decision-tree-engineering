## Decision

Frontmatter is written and changed only by the tool; agents never hand-edit it. Every operation that carries an invariant (allocating an ID, rewriting references, writing both sides of a contradiction, checking parent rings, flipping status, writing the ledger) and every question the paradigm poses is its own dte command. A frontmatter field that carries no invariant is changed through one guarded generic command, dte set, whitelisted to title and confidence. Provenance fields (made_by, by, date) are never edited after creation.

## Why

Supersedes B26 after its contest (recorded on B26 under Alternatives considered). B26 satisfied A7 and A4, but read literally it produced one command and one C node per single-field edit; the first, retitle, cost sixty lines for a one-field write. The variant satisfies the same rubric with strictly less machinery: the invariants that justify a dedicated command are named, and everything else shares one guarded write that already carries the B11 human-held check and a History line. A7 is served the same way B26 served it: no hand edit, no typo, no stall. A4 is served slightly better, since the owner's ad hoc edits never wait for a new command. The whitelist keeps set from becoming a bypass of retire, ratify, or move.

## Alternatives considered

Carried from B26, which this node supersedes.

### Contest 2026-09-05 by Claude Fable 5.1: variant wins

Rubric: A7 (agents run unattended, never re-question) and A4 (adoptable in a live project alongside structural tools).

- keep: every operation is a command, frontmatter never hand-edited. Passes A7 and A4. Cost: one command plus one C node per single-field edit that comes up (retitle was the first: ~60 lines, C16, a test, three doc lines).
- opposite: agents may hand-edit frontmatter; commands are conveniences. Cost 0. Fails A7: the misspelled field caught only by validate is recorded in B26's own Why, and hand edits skip History, line endings, and the human-held guard, so later agents re-question. Fails A4: the owner's daily actions would mean opening files.
- deletion: no rule; A7 and A4 decide case by case. Cost 0. Fails A7 the same way, more slowly.
- variant: frontmatter is still written only by the tool. Operations that carry an invariant (allocate an ID, rewrite references, write both sides of a conflict, check parent rings, flip status) each get a command. A field with no invariant is changed through one guarded generic write, dte set, whitelisted to title and confidence; provenance fields (by, date, made_by) stay out under A3. Cost: ~40 lines replacing retitle, one C node superseding C16. Passes A7 and A4 equally to keep and forecloses a class of future commands and C nodes.

Verdict: variant. Equal rubric fit, strictly less machinery below. Judge is the author of both B26 and C16; the rubric was written before the alternatives were built.
