## Decision

When an agent's environment (a harness hook, a permission layer) refuses an edit to governance, the agent stops that change and asks the owner for an authorization in chat that names the leaves. It never reaches the same result another way.

## Why

A refusal is the owner's boundary showing up where the tree cannot see it (A6). Routing around it makes the edit look authorized when nobody authorized it, which is the provenance failure A3 exists to prevent.

## Consequences

- The owner's in-chat word, naming the leaves, is the authorization; `dte authorize` records it on each leaf.
