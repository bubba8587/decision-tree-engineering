## Decision

All configuration lives in `dte.cfg` at the project root: one `key = value` per line, `#` comments. Recognised keys: `summaries` (A5), `protect_human` (B11), `authority` (B13), `retire` (B24), `links` (B30), `docs`, `specs`, `tests`, `agents` and `scan_self` (B37, C24), `broad_fraction` and `broad_min` (C8). Missing file or key means the default.

## Why

Three decisions now need a switch or a table, and A4 forbids anything that needs a parser dependency. A flat key-value file is the simplest format that a person can edit without documentation and a hand-written parser cannot get wrong. One file rather than several keeps "what is configured" answerable at a glance.

## Consequences

- `dte.cfg` is an artifact and cites the decisions whose switches it holds.
- New switches are added here, never as flags that must be remembered.
