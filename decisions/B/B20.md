## Decision

When an agent needs the owner to decide something, it asks in ordinary chat text: the options, a recommendation, and then it stops. It does not use the structured question dialog.

## Why

Stated by the owner on 2026-09-02 after the agent used the dialog to ask where to place two goals: "I don't like using the Claude question dialog. please ask directly in chat." A6 makes asking upward a routine act, so the form of asking matters; A5 wants decisions legible in the chat itself, and the dialog takes them out of it.

Scribed into the tree by the agent under B19, because until then this rule lived only in the agent's private memory.
