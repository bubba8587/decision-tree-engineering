## Decision

A leaf records a call a person could weigh and choose otherwise, written in the project's plain words. Anything that describes how the code carries a call out (call order, wrappers, file formats, internal names) is spec content, kept fluid with git as its record. The tripwire: a Decision names the call and its opposite, and a sentence that would still be true had the opposite been chosen belongs in the spec.

## Why

The tree holds why and specs hold what (A8). Mechanics written as leaves bury the calls a person must ratify under detail nobody can weigh, and every refactor then edits governance.

## Consequences

- `dte to-spec <ID> <spec>` moves a mechanics leaf's text into a spec and its citations to what it served.
- The protocol states this test where it introduces `dte new`, since an agent that reads only the protocol writes mechanics leaves.
- "Could someone reverse it and would something break" is not enough: a load order passes that and is still mechanics.
