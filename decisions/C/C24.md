## Decision

`layer_of(path)` checks the `tests`, `specs`, `agents` and `docs` globs in that order and falls back to code. `show` prints citing artifacts grouped by layer label; `coverage` lists in-effect non-core nodes with no citing test; `scope` counts every layer but docs as reach. The scanner skips the running tool file unless `scan_self = on`, which DTE's own repo sets, and `init` writes the tool's file name into .dteignore.

## Why

B37 wants the layers derived; B12 puts the globs in dte.cfg. A vendored tool's own citations point at DTE's tree and fail validate right after init; skipping the running file fixes every adopter at once.
