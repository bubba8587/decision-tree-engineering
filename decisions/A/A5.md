## Decision

Whenever a model refers to a decision in chat or in any output meant for a
person, it gives the ID together with a short, dense summary string. A bare
"A4" is never sufficient, unless the user has configured summaries off. The
tool instructs models to do this and supplies the string.

## Why

Stated by the project owner as an A-level decision. DTE is an AI-workflow
tool: most of the time a person reads a model's message, the decision file is
not open and not immediately available. An ID alone forces a lookup or, more
likely, is skimmed past, and the person ends up agreeing to things they did
not actually read. The summary keeps the decision legible at the point where
it is being discussed.

## Consequences

- Every node carries a summary string. The `title` field is that string and
  must be short and dense enough to stand in for the decision in a sentence.
- Every tool output that names a node prints the title beside the ID.
- Agent instructions forbid bare IDs in chat, and the tool surfaces the
  ID-plus-title form so it is the easy thing to copy.
- A configuration switch may turn summaries off; the default is on.
